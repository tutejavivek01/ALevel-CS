# AQA A Level Computer Science — reading material

One markdown file per chapter, extracted from *AQA AS and A Level Computer Science* (P.M. & R.S.U. Heathcote, PG Online, ISBN 978-1-910523-07-0).

**74 files · 89,122 words · 422 figures**

Each file carries YAML front matter (`chapter`, `spec_area`, `level`, `pdf_pages`) and ends with that chapter's exercises. Diagrams, logic circuits, state diagrams and truth tables are cropped from the source pages into `figures/` and referenced inline: the book is a scan, so those exist only as pixels and could not be reconstructed as text reliably.
